Each guide helps you do one task. It assumes that you have done the [Quickstart](/start/quickstart).

| You want to | Read |
|---|---|
| Fix a bug or add a small feature | [Build a change](/guides/build-a-change) |
| Build a new app or a large feature over many pull requests | [Run large work as a program](/guides/large-work) |
| Use the practice in a repo that already exists | [Bring the practice to an existing codebase](/guides/existing-codebase) |
| Keep a long session going while nobody watches it | [Run a session overnight](/guides/overnight) |
| Fix a mistake where it starts, so it does not come back | [Turn a review finding into a rule](/guides/review-finding-to-rule) |
| Change a setting: the secret tool, a model, a template answer | [Configuration](/guides/configure) |
| Choose links or copies, keep machines in step, give a client a copy | [Set up the practice for daily use](/guides/deploy) |
| Change the practice itself or these docs | [Contribute to the practice](/guides/contribute) |

# Brand files

These files come from the Komputa brand v1 (30 October 2026), in the `brand/`
folder of the Komputa brand repo. CI cannot read that repo, so the site keeps
copies. Copy them again when the brand version changes.

| File here | Brand file | Change |
|---|---|---|
| `brand/komputa-icon.svg` | `logos/komputa-icon-small-black.svg` | The fill is `currentColor`, so the logo follows the light and dark theme. |
| `../favicon.svg` | `favicon/favicon.svg` | None. It changes colour with the browser's theme by itself. |

The colours and fonts in `blume.config.ts` and `theme.css` come from
`style-guide/tokens.json`.
